Dodor Barcode Privacy Policy / 多多条形码 隐私政策

English

Last Updated: 2026-09-16

Introduction

Welcome to Dodor Barcode. We take your privacy seriously. This Privacy Policy explains how we collect, use, and protect your information. By using this app, you agree to the data practices described in this Privacy Policy.

About the App

Dodor Barcode is a lightweight companion tool for Dodor POS: enter or randomly generate a set of digits, pick a barcode symbology, and print the resulting barcode through a paired Bluetooth thermal printer. The app works entirely offline for its core features and does not involve any checkout, inventory, or transaction concepts.

Information Collection and Use

1. Local Data

This app stores the following data on your device:

Data Type Description Purpose
Barcode Records Barcode name, digits, symbology, and creation time Barcode history, reprinting
Printer Binding Info Bluetooth device name, MAC address, custom alias, paper width Connecting to and printing via your bound printer

Data Storage: This data is stored only on your local device and is never uploaded to any server. When you uninstall the app or clear app data, this data will be permanently deleted.

2. Automatically Collected Data

To improve app quality and user experience, we use the following third-party analytics services:

Firebase Analytics

Data Collected Purpose
App usage statistics Understand feature usage to improve the product
Device information Device model, OS version
App version Track version distribution
Approximate location Country/region level (based on IP address)

Firebase Crashlytics

Data Collected Purpose
Crash logs Identify and fix app issues
Crash stack traces Locate code problems
Device state information Understand device environment when crashes occur

Note: All automatically collected data is anonymous and does not include any information that directly identifies you personally.

3. Version Check Requests

This app periodically sends a request to our server to fetch a static configuration file, used only to check whether a newer app version is available. This request does not include any personal or device-identifying information.

Data Sharing and Disclosure

  • We do not sell your personal data
  • We do not share personally identifiable information with third parties
  • Firebase services are provided by Google and are subject to Google’s Privacy Policy
  • We may disclose information when required by law

App Permissions

This app may request the following permission:

Permission Purpose Required
Bluetooth (Nearby devices) Connect to and print via your Bluetooth thermal printer Optional (only needed to print)

User Choices and Controls

  1. Delete local data: Clear app data in device settings or uninstall the app
  2. Limit analytics data collection: Limit ad tracking in device settings
  3. Manage permissions: Revoke app permissions at any time in device settings

Data Retention

  • Local data: Retained until you actively delete it or uninstall the app
  • Analytics data: Handled according to Google Firebase’s data retention policy (typically 14 months)

Data Security

  • Core barcode and printer data is stored locally only and is not transmitted over the network
  • Analytics data is transmitted using HTTPS encryption
  • Regular app updates to fix security vulnerabilities

Children’s Privacy

This app is not designed for children under 13, and we do not knowingly collect personal information from children. If you are a parent or guardian and discover that your child has provided us with personal information, please contact us.

Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Updated policies will be posted within the app or on this page with an updated “Last Updated” date. For significant changes, we will notify you through in-app notifications or other means. Continued use of the app indicates your acceptance of the updated Privacy Policy.

Contact Us

If you have any questions, comments, or requests regarding this Privacy Policy, please contact us:

  • Email: contact@dodor.app

We will respond to your request within a reasonable timeframe.

Google Play Data Safety Supplement

For ease of completing the Google Play Console Data Safety form, here is a data collection summary:

Data Type Collected Shared Optional
Location Approximate (country level) No No
App activity Yes No No
App info Crash logs No No
Device IDs Yes (Android ID) No No
Personal info / Financial / Photos / Contacts, etc. No - -
  • Data is encrypted in transit
  • Users can request data deletion
  • No user data is shared with third parties

はじめに

ドドールバーコード（Dodor Barcode）をご利用いただきありがとうございます。私たちはお客様のプライバシー保護を重視しています。本プライバシーポリシーは、当社が情報をどのように収集・利用・保護するかを説明します。本アプリを利用することで、本ポリシーに記載のデータの取り扱いに同意したものとみなされます。

アプリについて

ドドールバーコードは「ドドールPOS」の相棒アプリです。数字を入力またはランダム生成し、バーコード形式を選ぶだけでバーコードを生成し、ペアリングした Bluetooth 感熱プリンターで印刷できます。主要機能はネット接続なしで利用でき、会計・商品管理・取引といった概念は一切含みません。

情報の収集と利用

1. ローカルデータ

本アプリは以下のデータを端末内に保存します：

データの種類 説明 目的
バーコード記録 バーコード名、数字、バーコード形式、作成日時 バーコード履歴、再印刷
プリンターのペアリング情報 Bluetooth デバイス名、MAC アドレス、任意の名称、用紙幅 ペアリング済みプリンターへの接続と印刷

データの保存について：これらのデータは端末内にのみ保存され、いかなるサーバーにもアップロードされません。アプリをアンインストールするか、アプリのデータを消去すると、これらのデータは完全に削除されます。

2. 自動的に収集されるデータ

アプリの品質とユーザー体験を改善するため、以下のサードパーティ分析サービスを利用しています：

Firebase Analytics（アプリ分析）

収集するデータ 目的
アプリ利用状況 機能の利用状況を把握し製品を改善する
デバイス情報 機種・OS バージョン
アプリのバージョン バージョン分布の把握
おおよその位置 国／地域レベル（IP アドレスに基づく）

Firebase Crashlytics（クラッシュ分析）

収集するデータ 目的
クラッシュログ 不具合の特定と修正
スタックトレース コードの問題の特定
デバイス状態情報 クラッシュ発生時の環境の把握

注記：上記の自動収集データはすべて匿名であり、お客様個人を直接特定できる情報は含みません。

3. バージョン確認リクエスト

本アプリは新しいバージョンの有無を確認するためだけに、当社サーバーへ定期的にリクエストを送り、静的な設定ファイルを取得します。このリクエストには個人情報やデバイスを特定する情報は含まれません。

データの共有と開示

  • お客様の個人データを販売することはありません
  • 個人を特定できる情報を第三者と共有することはありません
  • Firebase は Google が提供しており、関連するデータ処理は Google のプライバシーポリシー に従います
  • 法律で要求される場合には情報を開示することがあります

アプリの権限

本アプリは以下の権限を要求する場合があります：

権限 目的 必須かどうか
Bluetooth（付近のデバイス） Bluetooth プリンターへの接続と印刷 任意（印刷時のみ必要）

ユーザーの選択とコントロール

  1. ローカルデータの削除：端末の設定でアプリのデータを消去するか、アプリをアンインストールします
  2. 分析データ収集の制限：端末の設定で広告トラッキングを制限します
  3. 権限の管理：端末の設定でいつでもアプリの権限を取り消せます

データの保持

  • ローカルデータ：お客様が自ら削除するか、アプリをアンインストールするまで保持されます
  • 分析データ：Google Firebase のデータ保持ポリシーに従って処理されます（通常 14 か月）

データセキュリティ

  • 主要なバーコード・プリンターデータは端末内のみに保存され、ネットワークを介して送信されません
  • 分析データは HTTPS による暗号化で送信されます
  • セキュリティ上の脆弱性を修正するため、アプリを定期的に更新します

子どものプライバシー

本アプリは 13 歳未満の子どもを対象としておらず、子どもの個人情報を意図的に収集することはありません。保護者の方で、お子様が当社に個人情報を提供したことに気づいた場合は、ご連絡ください。

本ポリシーの変更

本プライバシーポリシーは随時更新されることがあります。更新後のポリシーはアプリ内または本ページに掲載し、「最終更新」日を更新します。重要な変更がある場合は、アプリ内通知などでお知らせします。アプリの利用を継続することで、更新後のポリシーに同意したものとみなされます。

お問い合わせ
