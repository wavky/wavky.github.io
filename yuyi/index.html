邮译：在网页邮箱里双语阅读英文邮件

邮译 (Yuyi) 是一个 Firefox 插件：在网页邮箱里，把英文邮件的中文译文逐段插在原文下方，原文保持不动，双语对照阅读。

为什么做

Firefox 确实自带网页全文翻译功能，但在网页邮件这个场景上使用并不顺手：它按整个页面的语言判断要不要翻译，而我的情况是邮箱界面是中文、只有邮件内容是英文，这时它往往连翻译按钮都不出现。然而就这么个基础功能，2026 年了仍然没有官方或好用的第三方解决方案。

再则，就算用上 Firefox 全文翻译了，机器翻译的准确度也有待商榷。整页替换之后原文就没了，译错、漏翻都无从察觉。所以邮译只翻邮件正文，把译文放在每段原文下面：既能顺带学学英文，也能随时对照原文，确认译文有没有错漏。

如今 AI 编码大环境下，开发一个小工具的心智成本、时间成本近乎为零。只要有需求、有想法，人人都能轻松定制属于自己的趁手工具，这是个好年代。

特点

  • 本机离线翻译：翻译引擎和模型来自 Mozilla，与 Firefox 内置翻译同款。邮件内容只在本机处理，不发送到任何服务器，不需要云端付费，也不需要注册账号。
  • 专注适配网页邮件这个场景：自动定位邮件正文区域，针对性提供翻译服务。目前内置适配了阿里企业邮箱和 Gmail，打开即用；其他网页邮箱只需手动点选一次正文所在的区域，之后自动记住。
  • 只做英译中：中文段落保持原样；引用的历史邮件也可以一起翻译。
  • 常驻自动翻译：开启插件翻译后，看下一封邮件不用再按一次。

使用

打开一封英文邮件，按 ⌥⇧B（Windows 上是 Alt+Shift+B），或点工具栏上的邮译按钮，显示或隐藏译文。

第一次使用时会下载约 40 MB 的英译中模型，之后都在本机翻译。

目前只支持英译中。译文质量取决于本地模型，日常商务邮件基本通顺，个别术语偶尔会译偏。

安装

邮译没有在 Firefox 附加组件商店上架，安装包经 Mozilla 签名后在本站发布，装好后 Firefox 会定期从本站检查更新、自动升级。

  1. 用 Firefox（142 或更新的版本）点击文章开头的「获取 Firefox 扩展」按钮。
  2. Firefox 会先询问是否允许本站安装附加组件，选择「继续安装」，再确认添加即可。
